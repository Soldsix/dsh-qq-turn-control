# dsh-qq-turn-control

[English](README.md) | 中文

## 概要

本预览版识别机器人已被接受回复的引用，并向可选独立意图分类器提供含发送者信息的有限上下文。它按群限制自动接话，并限制操作者明确配置的机器人发送者。普通成员明确 @ 和已知引用绕过人类自动接话额度。机器人身份由操作者配置，不从成员文字推断；本包不包含语言模型分类器。

## 使用与限制

本 bundle 需要 DSH 0.2.2-rc.1、dsh-im-kit 0.2.1 和 dsh-qq-chat 0.2.3，添加所有者设置控制器和运行行，默认关闭接话和意图判断。在 DSH Web 的 bundle 页面开启接话、配置引用、上下文及频率并保存。不能隐式替换其他策略。意图判断需要独立注册的 `qqTurnIntent` 服务；服务缺席时页面拒绝开启它，引用接话仍可使用。

引用索引仅包含已完成模型回复的接受回执，且限制内存。账号和会话必须一致；不确定发送或未知 ID 不匹配。意图上下文按时间、会话、消息数和字符数限制，并拒绝超过 6400 万字符的设置。每次调用的临时别名标注发送者、@ 对象、已知引用目标及机器人回答的收件人。未知引用不暗示收件人。用户文字仍可能包含身份，媒体标签不代表已读取内容。明确引用或 @ 其他成员时直接忽略，不调用分类器。私聊不变。

分类器或 Chat 基础规则选中的免 @ 续聊默认每群每 60 秒最多 3 次尝试，至少间隔 8 秒。`default` 转为忽略；分类器异常由 Chat 记录诊断，不再触发同一发送者续聊回退。普通成员明确 @ 和已知的机器人回答引用绕过自动接话额度。`botIds` 配置经过认证的发送者 ID，默认每个其他机器人每群每 60 秒最多 3 次、全群共 6 次；其未明确寻址消息直接忽略。所有上限可配置，同步预留额度，生成或发送失败仍消耗一次。保存、淘汰、过期或重启会重置临时状态。禁用会取消并等待自身调用结束；Chat 原消息、记忆及分类器 Session 均保留。见[升级指南](docs/upgrade-guide/v0.1.0/conservative-multi-party/guide.md)。

<a id="testing-and-privacy"></a>
下载独立发行包后，使用 `dsh plugin --profile <profile> add <archive.tgz>` 安装。共享库和 Chat 代码作为公开发行包依赖解析；工作 profile 仍需启用 Chat 服务。隔离 SDK/Web 验收使用固定版本 pnpm，并补齐公开声明的必要 DSH peer，不借用祖先依赖。

## 测试与隐私

`npm test` 构建软件包并运行本地合成接话和控制器测试。`npm run test:native -- --im-kit-archive <library.tgz> --chat-archive <chat.tgz>` 将独立软件包安装到隔离 DSH SDK profile，使用受控本地模型端点。测试不发送 QQ 消息。原生检查覆盖引用追问、跨群隔离、明确寻址和重复消息抑制，不能据此证明真实 QQ 投送或自然对话质量。

关闭意图判断时，本插件不保留消息正文。开启后将有限群文字交给指定分类器，由分类器负责模型请求及持久化 Session。每个临时群窗口有随机上下文 ID，完全过期、淘汰或重启会更换。合成测试包含三种不同的 15 人路由场景及并发预留额度；受控分类器不能证明语言智能水平。原生 SDK 和独立无界面 Web 测试使用已安装 bundle；真实 QQ 收发、Desktop、其他机器人身份发现、自然对话质量及逐张表情包限流仍需单独验证。本策略限制 Chat 回复尝试，不控制独立后台发送。
