# dsh-qq-turn-control

[English](README.md) | 中文

## 概要

本预览插件识别同一账号、同一会话中对机器人已成功发送消息的有效引用。可选接口能够把近期上下文交给另行安装的意图分类器；本包尚未包含分类器。没有分类器时，其他消息交回聊天插件的既有策略。其他机器人识别和自动对话降频仍未完成。

## 使用与限制

本 bundle 需要 DSH 0.2.2-rc.1、dsh-im-kit 0.2.1 和已公开的 dsh-qq-chat 0.2.1。它添加所有者设置控制器和运行条目；策略和可选意图判断默认关闭。在 DSH Web 中打开该 bundle，启用接话并保存，同一页面可配置引用与上下文的限制。已有其他接话策略占用服务时，启用会失败。意图判断需要另行注册 `qqTurnIntent` 服务；服务缺失时页面会拒绝启用。若 profile 在服务启动前已配置启用，引用接话仍可使用，页面会显示分类器缺失；意图判断回退到基础规则直至服务出现。本包本身没有内置兼容的分类器。

只有模型完成且发送收据确认接受的回复才进入有界内存索引。其他群或账号的结果、发送状态不确定的结果以及未知回复 ID 均不会匹配。启用意图判断时，在内存中临时保留近期已接纳的群文字和已接受的机器人回复，按时间、会话数、消息数及单条字符数限制；固定安全上限会拒绝超过 6400 万字符的配置。分类器只收到该群候选消息之前的上下文和按单次调用生成的成员别名，包括被提及者的别名；未知引用只标明存在引用，不推断其目标。用户文字自身仍可能包含身份信息。媒体只标明类型，不代表已经读懂内容。保存设置或重启策略会清空两种索引。群消息明确指向机器人及私聊继续按 Chat 插件原有规则处理。策略缺失或失败时回退到原有规则，失败会发出本地诊断。

停用或卸载策略时，先停止新判定、取消自身分类调用并等待结束，再完成卸载；同时清理暂存窗口，不删除 Chat 日志或分类器 Session。

<a id="testing-and-privacy"></a>
下载独立发行包后，使用 `dsh plugin --profile <profile> add <archive.tgz>` 安装。共享库和 Chat 代码作为公开发行包依赖解析；工作 profile 仍需启用 Chat 服务。隔离 SDK/Web 验收使用固定版本 pnpm，并补齐公开声明的必要 DSH peer，不借用祖先依赖。

## 测试与隐私

`npm test` 构建软件包并运行本地合成接话和控制器测试。`npm run test:native -- --im-kit-archive <library.tgz> --chat-archive <chat.tgz>` 将独立软件包安装到隔离 DSH SDK profile，使用受控本地模型端点。测试不发送 QQ 消息。原生检查覆盖引用追问、跨群隔离、明确寻址和重复消息抑制，不能据此证明真实 QQ 投送或自然对话质量。

意图判断关闭时，策略不保留消息正文。启用后会暂存在内存中，并交给选定的分类器；模型请求和持久化由分类器负责。每个内存中的群窗口都有随机、不含群号的上下文标识，供分类器隔离会话；窗口全部过期、被淘汰或重启后标识会改变。分类器仍须自行限制并隔离所使用的 Session。请单独保护 profile 和 Chat 日志。隔离无头 Web profile 已验证设置保存及明暗、窄屏布局。跨平台执行结果见 CI；桌面端、真实 QQ 通道、独立原生分类器组合和自然多人接话质量仍需验证。此预览包不代表自然多人对话或全部机器人控制均已完成。
