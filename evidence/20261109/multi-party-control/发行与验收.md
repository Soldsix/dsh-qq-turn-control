# 多人接话与频率控制 0.2 开发预览

已发行 `0.2.0-development`，源码为 `affac7198eb24f1fed3b8bfb82265c9a920c64ad`，SHA256 为 `1ee074f16cf4fa08e9f55b26d5768af49b5eb47df9dbf7ef9de9ffae79a1a16e`。匿名公开下载与候选一致。Windows/Linux 9 项 CI 全部通过。

Node 22/24 各 32 项测试通过，包含忙群、插话、机器人互聊三套 15 人路由样例；这些使用受控分类器，不是语言智能基准。真实 DSH SDK 的 13 项检查经原生模型适配器发出 15 次受控回环请求；8 项真实 DSH Web 检查和 335 份严格声明检查通过，28 个安装文件一致，不借用祖先依赖。

所有免 @ 续聊共用最终额度，包括不启用意图分类器时的 Chat 基础续聊。明确 @ 的普通成员、已识别的机器人回答引用绕过该额度。已配置机器人按群、账号和发送者限额；身份不由文字或昵称推断。已知引用目标与机器人回答的原收件人通过临时别名传给分类器。

已实际验证 15 条并发机器人 @ 仍受限、普通成员随后明确 @ 正常、重复来源不重复生成、禁言跳过分类、配置重载，以及卸载重装不改变聊天库校验值。人设、skills、长期记忆及正式服务均未操作。

本轮安装曾在父依赖尚未发布时因公开 404 停止；父依赖按顺序发布后，最终 SDK、Web 与消费者均通过公开依赖解析。中间使用候选覆盖的记录单独保留，不冒充公开依赖验收。

真实模型语义质量、自动发现其他机器人、复杂媒体上下文、逐张表情包限流及实际 QQ 客户端投递仍待单独验收。预发布 Host 目标为 DSH 0.2.2-rc.1，公开应用要求 Node >=24.9；Node22 仅记录兼容测试。
